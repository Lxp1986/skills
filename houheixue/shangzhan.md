# 商战转译：把厚黑学翻译成现代打法

> 转译原则：里子是厚黑，面子因时因地。以下为框架的现代应用推演，非原文。

## 求官六字 → 拿资源六字

| 字 | 原意 | 商战转译 |
|---|---|---|
| 空 | 放下一切、耐心 | All-in 一个赛道；对结果有耐心，不追风口 |
| 貢 | 有孔必钻、无孔开孔 | 找缝隙：有门路钻大，没门路创造门路（新品类、新渠道） |
| 沖 | 吹牛 | PR 与包装：会做更要会讲故事，融资路演即"沖" |
| 捧 | 捧场 | 抬高客户/合作方：让对方舒服，单子好谈 |
| 恐 | 恐吓（有分寸） | 亮筹码：让对方知道失去你的代价；竞对施压点到为止 |
| 送 | 送东西 | 利益分享：给渠道、给关键人实在的好处 |

## 做官六字 → 组织生存六字

| 字 | 原意 | 现代转译 |
|---|---|---|
| 空 | 空洞、留退路 | 说话留余地，决策留 B 计划；永远不把自己钉死 |
| 恭 | 对上卑躬 | 对上管理：老板的身边人（秘书、司机）一样搞定 |
| 繃 | 对下立威 | 对下立规矩；但"看饭碗在谁手里"——核心员工面前要收敛 |
| 兇 | 为达目的不顾一切 | 关键决策果断（如裁员、砍业务），但**必须蒙一层"为公司好"的叙事** |
| 聾 | 笑骂由他 | 屏蔽噪音：舆论、对手抹黑不影响既定路线 |
| 弄 | 落到利 | 一切经营最终落到利润；前面都是手段，"弄"是目的 |

## 二妙法 → 现代剧本

- **锯箭法**：表态 + 推后。"这个方向我完全支持，具体落地让 XX 牵头出方案。"——适合不想背锅的场合。
- **补锅法**：先放大问题，再带着方案救场。咨询行业标准打法；内部改革也可用（先让旧流程的痛显形）。

## 总纲（李宗吾结论，现代版）

1. **永远糊一层**：对道学先生糊"仁义道德"，对性学朋友糊"恋爱神圣"，对马克思朋友糊"阶级斗争"——现代版：对投资人糊"长期主义"，对员工糊"共同成长"，对监管糊"合规"。**面子的话术随对象变，里子的利益计算不变。**
2. **阴用其言而显弃其身**（韩非子）：心里供着厚黑，嘴上骂着厚黑。对外人设永远是"厚道人"。
3. **王莽教训**：失败不是因为黑，是因为**露出了黑**。手段的隐蔽性与手段本身同等重要。

## 反模式：厚黑过头的代价

- **认真厚黑终归失败**（李宗吾自警）：把手段当信仰，路越走越窄。铠甲穿久了会长进肉里。
- **恐用过度**：对方老羞成怒，从"给官"变成"作对"——筹码亮出来是威慑，砸出去是战争。
- **补锅补不起**：明季武臣之鉴。敲之前先算自己有没有补的能力。
- **只厚不黑（韩信）/ 只黑不厚（范增）**：单腿走路，遇到双全的对手必败。
- **取箭头的人最危险**（岳飞、于谦）：动实质格局前，先掂量自己的护甲够不够。
