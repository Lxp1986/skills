# 鬼谷子：说服与权谋的操作系统

**来源**：梁·陶弘景注本《鬼谷子》十二篇 + 《本经阴符七术》+《持枢》+《中经》（公版原文，见 `/tmp/guiguzi.txt`）
**一句话**：先捭阖定开合，再反应听虚实，揣情得其欲，摩意动其心，飞箝而取之——"得其情乃制其术"（内楗篇）。

## 核心心智模型

1. **捭阖**（开合总纲）：捭者开也、言也、阳也；阖者闭也、默也、阴也。开口让人说话是"捭"（料其情），闭口让他自说是"阖"（结其诚）。"口者，心之门户也"——一切信息都从这扇门进出，你要做守门人。
2. **反应**（反听）：话不投机不硬顶，"言有不合者，反而求之，其应必出"。反问、激将、钓鱼，让对方自己把底牌翻出来。
3. **揣情**（情报）：极喜极惧时最藏不住，"必以其甚喜之时，往而极其欲也；必以其甚惧之时，往而极其恶也"。"情变于内者，形见于外"——看外显推内情。
4. **摩意**（试探推动）："摩者，揣之术也"——揣知方向，摩是动手。以其所欲微摩之，看内符应不应。"圣人谋之于阴，故曰神；成之于阳，故曰明"——谋划在暗处，成事在明处。
5. **飞箝**（锁定）："引钩箝之辞，飞而箝之"——先飞扬声誉让他露情（空往），再箝持令其不得脱（实来）。"用之于人则空往而实来"。
6. **抵巇**（战机）："巇始有眹，可抵而塞，可抵而却，可抵而息，可抵而匿，可抵而得"——见微隙即行动，五种抵法按情势选。
7. **决**（决断）："凡决物，必托于疑者"——有疑才需决；"决情定疑，万事之基"。

## 谈判五步流程

1. **捭阖开场**：先阖（听）后捭（说）；与阳言者依崇高（谈愿景），与阴言者依卑小（谈风险）。
2. **反应听牌**：对方话不合我意，不反驳，反问回去，"其应必出"。
3. **揣摩试探**：摸其所好恶；以其所欲微摩之，看反应再定深浅。
4. **飞箝锁定**：给甜头/声誉让他开口，拿到关键信息后箝住——书面确认、公开承诺。
5. **决疑收尾**：对方犹豫时帮他"决"——把利害摆成符验，让他觉得是自己做的决定。
