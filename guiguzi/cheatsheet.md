# 鬼谷子速查：一页决策表

## 谈判前：摸底（揣篇量权）

| 查什么 | 问自己 |
|---|---|
| 大小 | 对方体量多大？我方呢？ |
| 众寡 | 双方团队、资源对比 |
| 货财 | 资金状况，谁更需要这单？ |
| 地形 | 市场位置，谁占地利？ |
| 亲疏 | 对方内部谁说了算？派系？ |
| 天时 | 时机对谁有利？谁更急？ |
| 好恶 | 对方拍板人最想要什么？最怕什么？ |

## 谈判中：话术选择

| 对方状态 | 用法 | 出处 |
|---|---|---|
| 谈愿景 | 阳言，依崇高往大了谈 | 捭阖 |
| 谈困难 | 阴言，依卑小往细了谈 | 捭阖 |
| 话不投机 | 不反驳，反问回去 | 反应 |
| 嘴严 | 问其所亲，侧面打听 | 揣篇 |
| 极喜时 | 顺着加码，探欲望边界 | 揣篇 |
| 极惧时 | 点破最坏情况，探真正怕什么 | 揣篇 |
| 要试探 | 以其所欲微摩之，看反应 | 摩篇 |
| 要锁定 | 书面确认 / 公开承诺 / 第三方见证 | 飞箝 |
| 对拍板人 | 言奇：非常之功 | 谋篇 |
| 对办事者 | 言私：个人利益 | 谋篇 |
| 情绪上头（病怨忧怒喜） | 闭嘴，改天再谈 | 权篇 |

## 见人说人话（权篇）

智者→博 | 贵者→势 | 富者→高 | 贫者→利 | 贱者→谦 | 勇者→敢

## 战机判断（抵巇）

裂缝初现 → 问：救得回来吗？
- 能 → 抵而塞之（补救）
- 不能 → 抵而得之（收割）
- 外部来犯 → 抵而却之
- 内部萌生 → 抵而息之
- 时机未到 → 抵而匿之（按住）

## 收尾五可决（决篇）

名利双收 ✓ | 顺手可成 ✓ | 不得已而为 ✓ | 避祸 ✓ | 趋福 ✓
→ 把方案套进这五条讲，对方自己点头。

## 内功七术（本经阴符）

盛神（养精神）→ 养志（寡欲则志坚）→ 实意（心安静虑深远）→ 分威（不怒自威）→ 散势（待间而动）→ 转圆（随机应变）→ 损兑（专心察机）

## 一句话总纲

**"得其情乃制其术"** —— 没摸清对方就出手，必翻车（"不得其情而说之者，见非"）。
