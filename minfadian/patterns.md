# 实务模式（Patterns）

面向在中国工作和做生意的商事主体的可复用操作模式。

## Pattern 1：合同审查八项清单
**When to use**：签署任何金额较大、期限较长的合同前。
**How**（对照第470条）：
1. 当事人信息：名称、统一社会信用代码、法定代表人、签约代表授权书（防172条表见代理/171条无权代理）
2. 标的与数量质量：规格型号、验收标准（511条约定不明时按国家标准）
3. 价款与支付：金额、币种、支付节点、发票条款（670条禁砍头息方向）
4. 履行期限地点方式：交货/完工节点、地点、运输方式
5. 违约责任：违约金比例（585条防过高被调减）、定金二选一（588条）
6. 解除条件：约定解除（562条）+ 法定解除兜底（563条）；解除通知方式（565条）
7. 争议解决：诉讼或仲裁**二选一**，写清管辖法院/仲裁机构（507条争议解决条款独立）
8. 格式条款自查：己方提供的，删"概不负责""最终解释权"（497条）
**Trade-offs**：审查越细谈判周期越长；小额高频交易可用标准模板+关键项勾选。

## Pattern 2：担保方式选择矩阵
**When to use**：放款、赊销、大额交易前设计担保。
**How**：
| 目标 | 首选工具 | 条文 | 注意 |
|---|---|---|---|
| 不动产担保 | 抵押，登记设立 | 402条 | 必须登记；401条禁流押 |
| 设备/存货担保 | 动产抵押，登记对抗 | 403条 | 不登记=裸奔 |
| 应收账款/票据 | 权利质押，登记/交付 | 441/445条 | 445条登记+通知债务人 |
| 货物在手 | 留置 | 447条 | 须合法占有+60日宽限期453条 |
| 找人担保 | 连带责任保证 | 686条 | 必须写明"连带"四字，否则默认一般保证 |
| 人保+物保并存 | 合同约定实现顺序 | 392条 | 无约定先执行债务人自己的物保 |

## Pattern 3：应收账款时效管理
**When to use**：所有赊销、借款、服务费回收。
**How**：
1. 台账记录每笔债权的到期日（188条3年）
2. 到期前6个月预警；到期后立即书面催收（EMS/邮件留痕）→ 构成时效中断（195条），重新计算3年
3. 争取对方**书面确认**欠款（对账单、还款计划）——最强的中断证据
4. 2年6个月无结果→ 启动诉讼/仲裁（别等到第3年）
5. 起诉时对方可能提时效抗辩（193条法院不主动适用），己方备好中断证据链
**Trade-offs**：频繁催收影响客户关系；大额债权优先走法律程序。

## Pattern 4：解除合同的标准动作
**When to use**：对方根本违约、不可抗力、情势变更时想退出。
**How**：
1. 取证：违约事实（563条法定情形）或协商一致（562条）
2. 发**书面解除通知**（565条）：EMS+邮件+微信三通道，写明解除依据和事由
3. 通知到达即解除——保留送达凭证（签收记录、公证书）
4. 解除后：未履行终止，已履行按566条恢复原状/赔偿
5. 注意除斥期间（564条）：约定或法定期限内行使
**Anti-pattern**：只打电话口头说"不做了"——无送达证据，解除效力存疑。

## Pattern 5：公司印章与授权管理
**When to use**：日常经营，防172条表见代理。
**How**：
1. 公章专人专管，用印审批登记（时间、事项、经办人）
2. 严禁在空白合同/介绍信上盖章
3. 业务员授权委托书载明权限范围+期限；离职/调岗当日书面通知主要客户
4. 法定代表人越权签约对外有效（504条）——靠章程限制不了善意相对人，只能靠内部追责
**Trade-offs**：管得过严影响业务效率；分级授权（金额分档）平衡。

## Pattern 6：企业侵权风险四象限巡检
**When to use**：每季度/新业务上线前。
**How**：
1. 用工（1191条）：高风险岗位保险+操作规程+内部追偿条款
2. 产品（1202/1207条）：质量体系+产品责任险；食品药品儿童产品重点盯
3. 场所（1198条）：防滑警示监控巡查记录——留痕即免责证据
4. 网络（1194/1195条）：舆情监测+平台通知处理流程（通知—删除）
**Trade-offs**：全覆盖成本高；按行业排优先级（制造重产品、零售重场所、互联网重网络）。

## Pattern 7：家企传承三件套
**When to use**：企业主财富与股权传承规划。
**How**：
1. 约定财产制（1065条）：婚内书面约定，公证+通知主要债权人以对抗第三人
2. 遗嘱（1133–1139条）：打印遗嘱每页签名+2见证人（1136条）；指定遗嘱执行人兼遗产管理人（1145条）
3. 债务预案：1159/1161条限定继承；大额个人担保与家庭财产隔离
**Trade-offs**：家族成员知情程度与方案保密性的平衡；建议配合持牌律师+税务师。

## Pattern 8：高空抛物/物业风险
**When to use**：物业管理、业委会、业主。
**How**（1254条）：物业装监控全覆盖+定期巡查+业主群普法→ 履行"必要安全保障措施"；出事后配合公安调查→ 锁定具体侵权人，避免整栋补偿。
