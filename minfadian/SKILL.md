# 中华人民共和国民法典 Skill

**版本**：2020-05-28通过，主席令第45号，2021-01-01施行 | **结构**：7编1260条 | **生成**：2026-10-02
**定位**：团队"法务"角色的知识库，服务于在中国工作和做生意的商事主体。提炼+实务解读，不复制法条全文。

## How to Use This Skill

- **直接问法律问题** — 如"保证合同没写保证方式怎么办"，我按相关章节作答并给出条文号
- **查条文** — 问"第686条讲什么"，我给出该条要点与实务含义
- **读章节** — 说"读ch03"，我加载合同编全文
- **审合同/搭担保/做合规** — 用 patterns.md 的清单和矩阵逐步过
- 问到 skill 未覆盖的细节时，我会先读对应章节文件再回答

## Core Frameworks & Mental Models

**总则三件套（一切商事争议的起点）**：先看主体合格吗（自然人/法人/非法人组织，17–20/57/102条）→ 再看行为有效吗（143条三条件；153条违反强制性规定无效；154条恶意串通无效）→ 最后看时效（188条3年，195条中断重算，193条法院不主动适用）。表见代理（172条）是印章与授权管理的头号风险。

**物权看公示**：不动产看登记（209条）、动产看交付（224条）。合同有效≠物权转移（215条）。动产抵押、应收账款质押必须登记否则对抗不了第三人（403/445条）。流押流质条款一律无效（401/428条）。人保+物保并存时实现顺序先看合同约定，无约定先执行债务人自己的物保（392条）。

**合同编三支柱**：465条合同相对性 → 509条全面履行 → 577条违约责任。**686条是民法典时代最重要的实务反转**：保证方式约定不明→按一般保证（先诉抗辩），债权人务必写明"连带责任保证"四字。解除、转让、撤销都是要式动作：565条解除须通知到达；545条债权转让通知债务人；541条撤销权1年/5年除斥。违约金与定金二选一（588条），赔偿以可预见为限（584条）。

**侵权四象限**：用工（1191条员工职务行为公司买单）、产品（1202条生产者无过错+1207条惩罚性赔偿）、场所（1198条安全保障义务，留痕即免责证据）、网络（1195条通知—删除）。发包用承揽关系隔离风险（1193条），但选任指示过失是缺口。

**家企防火墙**：1064条"共债共签"——大额债务让配偶签字；1065条约定财产制对抗第三人须公示；1077条离婚冷静期30日；1123条继承顺序遗赠扶养协议＞遗嘱＞法定；1136条打印遗嘱每页签名+2见证人；1161条继承人以所得遗产实际价值为限还债。

**人格权**：992条不得放弃转让继承；997条人格权禁令是舆情危机急诊；用真人形象/个人信息先拿授权（993/1018/1035条）。

## Scope & Limits

1. 本 skill 覆盖民法典正文的提炼与商事实务解读；**不含**司法解释、指导性案例、地方性法规——实务中这些与法条同等重要，须另行查阅。
2. **静态知识须核对现行有效文本**：法律持续修订，引用条文用于真实事项前，必须到国家法律法规数据库（flk.npc.gov.cn）等官方渠道核对文本、司法解释与施行时间。
3. 本 skill 不构成法律意见；重大交易、诉讼、家事、遗产事项须咨询**持牌律师**。
4. 刑事、行政、税法、劳动法、公司法、涉外法律不在本 skill 范围内，涉及交叉时我会提示。
5. 条文解读为提炼性质，**以法条原文表述为准**；版本号见 source-map.md。
