# 第一编 总则（第1–204条）

## Core Idea
总则编是民法典的"总开关"：它规定所有民事活动必须遵循的基本原则（平等、自愿、公平、诚信、公序良俗、绿色），界定"谁"可以参与民事活动（自然人、法人、非法人组织），以及民事法律行为"怎样才有效"。任何合同、交易纠纷，第一步都是回到总则检验：主体合格吗？行为有效吗？时效过了吗？

## 关键条文

**基本原则（第1–12条）**
- 第4条：民事主体法律地位一律平等
- 第5条：自愿原则——按自己意思设立、变更、终止民事法律关系
- 第6条：公平原则——合理确定各方权利义务
- 第7条：诚信原则——秉持诚实，恪守承诺（合同履行、谈判中的兜底条款）
- 第8条：不得违反法律，不得违背公序良俗（合同无效的常见依据）
- 第9条：绿色原则——节约资源、保护生态环境
- 第10条：法律没有规定的，可以适用习惯，但不得违背公序良俗
- 第12条：在中国境内的民事活动，适用中国法律（涉外业务的准据法起点）

**民事主体**
- 第13–16条：自然人的民事权利能力（出生—死亡）
- 第17条：18周岁以上为成年人；第18条：成年人为完全民事行为能力人
- 第19条：8周岁以上未成年人为限制民事行为能力人；第20条：不满8周岁为无民事行为能力人
- 第57条：法人定义——依法独立享有权利、承担义务的组织；第60条：法人以其全部财产独立承担民事责任（有限责任的基石）；第61条：法定代表人
- 第102–108条：非法人组织（个人独资企业、合伙企业等）——能以自己名义活动，但责任承担规则与法人不同

**民事法律行为的效力（第133–160条）**
- 第143条：有效三条件——行为人有相应行为能力、意思表示真实、不违反法律行政法规强制性规定且不违背公序良俗
- 第144条：无民事行为能力人实施的民事法律行为无效
- 第153条：违反法律、行政法规**强制性规定**的无效（注意：只有"强制性规定"才导致无效，管理性规定不必然无效——合同审查的关键区分）
- 第154条：恶意串通损害他人合法权益的无效（关联交易、低价转移资产的常见攻击点）
- 第155条：无效或被撤销的民事法律行为自始没有法律约束力
- 第157条：无效后的返还/折价补偿/过错赔偿

**代理（第161–172条）**
- 第162条：代理人在权限内以被代理人名义实施的行为，对被代理人发生效力
- 第167条：代理人明知代理事项违法仍实施，或被代理人明知代理人违法仍不反对——双方承担连带责任
- 第171条：无权代理——未经追认对被代理人不发生效力（相对人可催告、撤销）
- 第172条：表见代理——相对人有理由相信有代理权的，代理行为有效（**公司业务中最危险的一条**：业务员持盖章空白合同、长期交易惯例都可能构成表见代理）

**诉讼时效（第188–204条）**
- 第188条：普通诉讼时效**3年**；最长权利保护期间20年（自权利受到损害之日起算，不适用中止中断）
- 第193条：人民法院**不得主动**适用诉讼时效（必须由当事人主张——答辩时一定要提时效抗辩）
- 第194条：时效中止（最后6个月内有障碍）；第195条：时效中断（起诉、主张权利、同意履行——中断后重新计算）
- 第196条：不适用时效的情形（请求停止侵害、排除妨碍、消除危险；不动产物权/登记的物权请求权等）
- 第199条：撤销权、解除权等除斥期间——自知道或应当知道起算，届满消灭

## 商事实务要点

1. **签约前必查主体资格**：对方是法人（查营业执照、法定代表人身份）、非法人组织，还是自然人？与分公司签约注意其责任最终由总公司承担；与"筹备中"的公司签约，主体可能不适格。
2. **授权链管理**：凡委托他人签约，必须有书面授权委托书并载明权限范围和期限；警惕表见代理——收回业务员的空白盖章文件、及时书面通知客户授权变更。
3. **合同效力三查**：主体能力（143条）→ 意思真实（欺诈胁迫可撤销，148–150条）→ 不违反强制性规定（153条）。效力瑕疵的合同，钱货两空还可能丧失担保。
4. **时效是生命线**：应收账款、货款、借款到期后，3年内必须有"中断"动作（书面催款函、起诉、对方书面确认欠款）。财务和法务应建立时效台账，到期前6个月预警。
5. **20年最长保护期**：陈年旧账、历史遗留权属争议，先算20年——超过则实体权利不再受保护。

## 常见误区 / 反模式

- **"时效过了就自动失效"**：错。法院不主动适用（193条），对方不提时效抗辩，照样胜诉。所以起诉方不要自认时效已过；应诉方务必在答辩期首先审查时效。
- **"盖了章合同就一定有效"**：错。违反强制性规定（153条）、恶意串通（154条）的合同，盖章也救不了。
- **"分公司欠的钱与总公司无关"**：错。分公司不具有法人资格，其民事责任由总公司承担。
- **"口头授权也算数"**：对内也许，对外举证极难。重要授权一律书面。
- **"撤销权可以一直留着"**：错。撤销权、解除权有除斥期间（199条），过期消灭，不能中止中断。

## Worked Example

**场景**：A公司业务员李某持盖有A公司公章的空白合同，与B公司签订了200万元供货合同并收取预付款后失联。A公司称李某已离职、合同未经授权，主张合同无效。

**分析**：
1. 主体：A公司是法人，李某是代理人——审查代理权（171/172条）。
2. B公司有理由相信李某有代理权吗？公章真实 + 李某曾是业务员 + 长期交易惯例 → 构成表见代理（172条），合同对A公司有效。
3. A公司不能以"内部未授权"对抗善意B公司；A公司承担责任后可向李某追偿（内部关系另算）。
4. 若B公司明知李某已离职仍签约，则不构成表见代理，适用无权代理（171条）。

**结论**：公司必须管好公章和离职交接，对外发布授权变更通知，否则表见代理的锅自己背。

## Key Takeaways

1. 总则是所有商事争议的"第一性原理"：先看主体、再看行为效力、最后看时效。
2. 诚信（7条）和公序良俗（8条）是兜底武器，也是合同无效的常见入口。
3. 表见代理（172条）是企业印章和授权管理的头号风险。
4. 3年诉讼时效 + 中断规则（188/195条）是应收账款管理的法律骨架。
5. 法人以全部财产独立担责（60条）——注册资本的意义就在于此。
