# 第三编 合同（第463–988条）

## Core Idea
合同编是民法典篇幅最大的一编（526条），也是做生意天天打交道的法律。它分三块：**通则**（合同怎么成立、怎么生效、怎么履行、怎么解除、违约怎么办）、**典型合同**（买卖、借款、保证、租赁等19种有名合同的特别规则）、**准合同**（无因管理、不当得利）。核心精神：依法成立的合同受法律保护（465条），全面履行（509条），违约必担责（577条）。

## 关键条文

**合同的订立**
- 第463条：本编调整因合同产生的民事关系；第464条：合同是设立、变更、终止民事法律关系的协议
- 第469条：书面、口头或其他形式均可（但**重要合同一律书面**——举证之王）
- 第470条：合同主要条款清单（当事人、标的、数量、质量、价款、履行期限地点方式、违约责任、争议解决）——审合同时逐项打勾
- 第471条：要约+承诺；第473条：要约邀请（拍卖公告、招标公告、招股说明书——报价单到底是要约还是要约邀请，决定有没有约束力）
- 第479条：承诺是同意要约的意思表示；第484条：承诺通知到达时生效
- 第490条：合同书形式自双方**签名、盖章或按指印**时成立（只盖了骑缝章？只签了字没盖章？按490条判断成立时点）

**合同的效力**
- 第465条：依法成立的合同受法律保护；**合同相对性**——仅对当事人有约束力（向合同外第三人主张权利，先找法律另有规定）
- 第496条：格式条款定义（预先拟定、未协商）；**第497条：格式条款无效情形**（不合理免除己方责任、加重对方责任、排除对方主要权利）；第498条：争议时作**不利于提供方**的解释
- 第500条：缔约过失——订立过程中的欺诈、恶意磋商、泄露保密信息要赔（谈判桌上也不是法外之地）
- 第502条：依法成立的合同自成立时生效
- 第504条：法定代表人**越权**订立的合同有效（除非相对人明知）——对方盖了公章，就别纠结他有没有董事会决议
- 第505条：超越经营范围不影响合同效力
- 第506条：**免责条款无效**情形（造成对方人身伤害、因故意或重大过失造成对方财产损失的免责无效——"概不负责"告示牌的法律命运）
- 第507条：争议解决条款**独立性**——合同无效/解除不影响仲裁/诉讼条款（想赖掉仲裁，先看507条）

**合同的履行**
- 第509条：全面履行原则；第510条：约定不明可协议补充；第511条：仍不明的法定填补（质量按国家标准、价款按市场价、履行地按特征义务方所在地等）
- 第521条：连带债权债务
- 第525条：同时履行抗辩；第526条：先履行抗辩；第527条：**不安抗辩权**（对方经营恶化、转移资产、丧失信誉时可中止履行——供应商的保命条款）
- 第531条：债权人可拒绝部分履行
- 第533条：**情势变更**——基础条件发生无法预见、非商业风险的重大变化，继续履行明显不公时可请求变更/解除（疫情、政策剧变时的救济阀；注意：**商业风险不算**）
- 第535–536条：**代位权**（债务人怠于行使债权，债权人可代位向次债务人主张）；第538–539条：**撤销权**（无偿处分、明显不合理低价转让/高价受让、为他人债务担保——债权人可请求法院撤销）；第541条：撤销权除斥期间（知道起1年，行为发生起5年）

**合同的变更、转让、终止**
- 第544条：变更约定不明推定为未变更；第545条：债权转让（通知债务人即生效，未通知不对债务人生效）；第551条：债务转移**须经债权人同意**
- 第553条：合同权利义务概括转让
- 第557条：债权债务终止情形；第558条：终止不影响结算清理条款
- 第562条：协商一致可解除；第563条：**法定解除**（不可抗力、预期违约、迟延履行经催告、根本违约等）
- 第564条：解除权行使期限；第565条：**解除须通知对方，通知到达时解除**（微信、邮件通知的送达证据要留好）
- 第566条：解除后果（终止履行、恢复原状、赔偿损失）

**违约责任**
- 第577条：不履行/履行不符合约定→继续履行、补救、赔偿
- 第578条：**预期违约**——履行期届满前明确表示不履行的，可提前追责（不用等到交货日）
- 第580条：继续履行的例外（法律/事实上不能、标的不适于强制履行、费用过高、期限内未请求）
- 第581条：第三人替代履行的费用负担
- 第584条：**可预见规则**——赔偿额以违约方订立合同时**预见到或应当预见**的损失为限（签大合同时把潜在损失写进合同，就是在扩大可预见范围）
- 第585条：**违约金**——可约定；过分高于损失可请求调减（司法实践中超过损失30%常被认定过高）
- 第586–588条：**定金**——交付生效；给付方违约无权要回，收受方违约双倍返还；**违约金与定金二选一**（588条）

**典型合同精要（商事高频）**
- **买卖**（595条起）：第606条在途货物风险自合同成立时转移；第620条买受人及时检验义务；第623条检验期限未约定时签收单的推定；第626条价款支付
- **借款**（667条起）：第670条禁止预扣利息（砍头息按实际借款算）；**第680条禁止高利放贷**，利率不得违反国家规定（LPR 4倍红线看司法解释）
- **保证**（681条起）：第681条保证定义；第682条从合同属性；**第686条：保证方式约定不明→按一般保证**（民法典颠覆担保法的重大变化！以前是推定连带，现在推定一般——债权人务必在合同中写明"连带责任保证"四个字）；第687条一般保证（先诉抗辩权）；第691条保证范围；第692条保证期间不中止中断延长
- **租赁**（703条起）：第705条租期**最长20年**；第708条出租人维修义务；第716条转租须经同意；**第725条买卖不破租赁**；第726条承租人优先购买权；第731条危及安全的租赁物承租人可随时解除
- **融资租赁**（735条起）、**保理**（761条起：应收账款转让+资金融通，配合445条质押登记）
- **承揽**（770条起）、**建设工程**（788条起）：第793条施工合同无效但验收合格可参照约定折价补偿；**第807条承包人建设工程价款优先受偿权**（优于抵押权！发包人欠工程款，承包人是第一顺位）
- **技术合同**（842条起）：第850条非法垄断技术/侵害他人技术成果的合同无效
- **保管**（888条起）、**委托**（919条起）：第933条**任意解除权**（委托人和受托人可随时解除——找律师、找中介，先看这条）；**第391条**注意：第三人提供担保时债权人允许债务转移须经担保人书面同意
- **物业服务**（937条起）：第944条业主不得以未接受服务为由拒付物业费
- **中介**（961条起）：第965条**跳单条款**——接受中介服务后绕开中介成交的，仍须付报酬
- **合伙**（967条起）
- **准合同**：第979条无因管理（可请求偿还必要费用）；第985条不当得利（转错账、多付款的返还依据）

## 商事实务要点

1. **审合同八项**（按470条逐项）：当事人信息全吗？标的数量质量明确吗？价款与支付方式？履行期限地点方式？验收标准？违约责任对等吗？解除条件？争议解决（诉讼/仲裁选其一，写清管辖）？
2. **格式合同自查**：自己提供的格式条款（496条），把"概不负责""最终解释权归我方"删掉——497条下无效，还显得不专业。对方提供的格式合同，逐条审免责条款。
3. **保证条款四个字**：做债权人，让保证人写明"连带责任保证"，否则686条默认一般保证（先诉抗辩，执行难上加难）。同时约定保证期间（692条不中止中断，过期权利就没了）。
4. **不安抗辩的操作**：527条不是想用就用——要有"确切证据"证明对方经营恶化等情形，中止后要**及时通知**对方，对方提供担保后应恢复履行。证据不足的中止=自己违约。
5. **解除权行使**：565条——解除必须**通知**，通知到达生效。催告函、解除函用EMS/公证送达，微信邮件留痕。解除权有除斥期间（564条），别拖。
6. **违约金设计**：585条约定违约金，标准建议参照实际损失上浮；过高会被调减，过低可请求增加。定金不超主合同标的额20%（担保法规则仍有效）。
7. **情势变更≠商业风险**：533条门槛很高——原材料涨价、市场波动一般认定为商业风险。用好"不可抗力+情势变更"条款，把极端情形写进合同。
8. **债权转让与保理**：545条转让通知债务人；做保理/应收账款融资，445条登记+761条合同双保险，并书面通知债务人。

## 常见误区 / 反模式

- **"保证合同没写保证方式，对方就是连带保证"**：错！686条：约定不明→**一般保证**。这是民法典与旧担保法最大的反转之一，无数债权人吃过亏。
- **"合同解除不用通知，直接起诉就行"**：风险大。565条要求通知到达生效；起诉状副本送达可视为通知，但时点和证据都不如一封书面解除函干净。
- **"违约金写得越高越有威慑力"**：错。过分高于损失会被法院调减（585条），还可能被认定为格式条款无效（497条）。
- **"对方违约，我也可以不履行"**：要看情形。525/526条的同时/先履行抗辩有严格条件；不安抗辩（527条）需要确切证据+通知义务，任性中止=自己违约。
- **"口头承诺变更了合同"**：544条：变更约定不明推定为未变更。重要变更一律书面补充协议。
- **"定金和违约金可以都要"**：错。588条二选一，签约时想好哪个对你更有利。
- **"20年租约"**：705条：超过20年的部分无效。长租约拆成"20年+优先续租权"。

## Worked Example

**场景**：E公司（债权人）借款1000万给F公司，G公司董事长口头承诺"还不上我来还"，后补签保证合同但未写明保证方式。F公司到期未还款，E公司直接起诉G公司要求承担连带责任。

**分析**：
1. 保证合同成立：682条从合同，书面形式已补签，有效。
2. 保证方式：合同未写明→686条→**一般保证**，G公司享有先诉抗辩权：E公司必须先起诉F公司并经强制执行仍不能履行，才能要求G公司承担。
3. E公司直接诉G公司连带责任，法院会驳回或告知先诉F公司。
4. 保证期间：692条——合同若约定"保证期间2年"，该期间不中止中断，E公司必须在期间内主张权利。

**结论与补救**：E公司应在保证合同中写明"连带责任保证"及保证期间；已签的这份，立即对F公司提起诉讼并执行，同时在保证期间内向G公司书面主张权利。以后所有对外担保，法务审四个字：**连带责任**。

## Key Takeaways

1. 465条合同相对性+509条全面履行+577条违约责任=合同编的三根支柱。
2. 686条"约定不明→一般保证"是民法典时代最重要的担保实务变化。
3. 解除（565条）、转让（545/551条）、撤销权（538–541条）都是**要式动作**：通知、同意、除斥期间，一个都不能省。
4. 违约金（585条）与定金（586–588条）二选一；可预见规则（584条）决定你能赔多少。
5. 格式条款（496–498条）、免责条款（506条）是审合同的重灾区。
6. 情势变更（533条）门槛极高，别把商业风险当救命稻草。
