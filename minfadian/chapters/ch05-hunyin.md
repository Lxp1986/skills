# 第五编 婚姻家庭（第1040–1118条）

## Core Idea
婚姻家庭编调整身份关系，但对做生意的人有两大现实意义：**夫妻财产制**（公司股权、家庭财富与债务风险的防火墙）和**家企传承的起点**（继承编的前置）。核心逻辑：婚姻自由、一夫一妻、男女平等（1041条），财产上默认共同制、允许约定制（1062/1065条），债务上"共债共签"（1064条）。

## 关键条文

**一般规定与结婚**
- 第1041条：婚姻家庭受国家保护；实行婚姻自由、一夫一妻、男女平等
- 第1042条：禁止包办买卖婚姻、借婚姻索取财物、重婚、家庭暴力
- 第1043条：树立优良家风（倡导性条款）
- 第1046条：结婚须男女双方完全自愿；第1047条：婚龄男22/女20周岁
- 第1048条：直系血亲和三代以内旁系血亲禁止结婚
- 第1049条：须亲自到婚姻登记机关登记，**领取结婚证即确立婚姻关系**（仪式、宴席都不算数）
- 第1051条：婚姻无效情形（重婚、有禁止结婚的亲属关系、未到法定婚龄）
- 第1052条：胁迫结婚可撤销（1年除斥期间）；第1053条：**隐瞒重大疾病可撤销**（登记前须如实告知）

**夫妻关系与财产制**
- 第1062条：婚姻存续期间所得的工资、生产经营收益、知识产权收益等为**夫妻共同财产**（默认共同制——创业所得、公司分红原则上都是共同的）
- 第1063条：一方**个人财产**（婚前财产、专属生活用品、遗嘱/赠与中确定只归一方的财产等）
- 第1064条：**夫妻共同债务**=双方共同签名/事后追认的债务+一方为家庭日常生活需要的债务；超出家庭日常生活需要的个人名义债务**原则上不是共同债务**（债权人想追另一方，须证明用于共同生活、共同生产经营或共同意思表示——"共债共签"的举证责任在债权人）
- 第1065条：**约定财产制**——可约定婚内财产各自所有/共同所有/部分各自所有，约定须书面；**对内有效，对第三人须让第三人知道**（想用约定财产制隔离债务风险，必须让债权人知情，否则只约束夫妻内部）
- 第1066条：婚内分割共同财产的法定情形（一方隐藏转移变卖挥霍共同财产等）

**离婚**
- 第1076条：协议离婚须签书面离婚协议+亲自到登记机关申请
- 第1077条：**离婚冷静期30日**——申请后30日内任何一方可撤回；届满后30日内须共同领取离婚证（协议离婚变慢了，着急的走诉讼）
- 第1079条：诉讼离婚——调解无效、感情确已破裂的准予离婚（分居满2年、重婚家暴赌博吸毒等是法定情形）
- 第1084–1086条：子女抚养（2周岁以下原则归母，8周岁以上尊重意愿）、抚养费、探望权
- 第1087条：共同财产协议处理；协议不成法院按**照顾子女、女方和无过错方**原则判
- 第1088条：**家务劳动补偿**——一方因抚育子女、照料老人、协助另一方工作负担较多义务的，离婚时可请求补偿
- 第1090条：离婚经济帮助（一方生活困难，有负担能力一方给予适当帮助）
- 第1091条：**离婚损害赔偿**——重婚、与他人同居、家暴、虐待遗弃家庭成员等，无过错方可请求损害赔偿

**收养**
- 第1100条：无子女收养人可收养两名，有子女只能收养一名
- 第1111条：收养成立后适用父母子女关系规定，养子女与生父母的权利义务消除

## 商事实务要点

1. **夫妻共同债务防火墙**（1064条）：企业主以个人名义对外大额借款、担保，原则上**不是**夫妻共同债务——但债权人若能证明用于"共同生产经营"（比如借款进了夫妻共管的公司），配偶照样被追。反过来：你是债权人，借钱给已婚人士做生意，**务必让其配偶共同签字**，否则只能追一人。
2. **约定财产制的正确姿势**（1065条）：婚前/婚内书面约定财产归属，想对抗债权人必须让债权人"知道"（实践中：公证+书面通知主要债权人）。只夫妻俩知道的约定，防不了外部债务。
3. **股权与离婚**：一方持有的公司股权是共同财产（1062条），离婚分割时涉及股权转让——有限公司股东配偶分割股权受"其他股东过半数同意+优先购买权"限制（公司法衔接），实务中常折价补偿。
4. **家企传承衔接**：遗嘱（1133条）+约定财产制（1065条）+保险/信托，是企业主财富传承的组合工具，详见ch06。
5. **冷静期影响交易**：1077条下协议离婚至少31天——涉及离婚财产分割的资产处置（如卖房），交易对手要确认离婚证已领取，否则处分效力有瑕疵。

## 常见误区 / 反模式

- **"老公/老婆借的钱，另一半当然要一起还"**：错。1064条后，超出家庭日常需要的个人债务，债权人须举证"共同意思表示/共同生产经营"。"共债共签"是铁律。
- **"签了婚前协议就万事大吉"**：错。1065条约定只约束夫妻内部；对抗第三人须让第三人知道。且约定不能违背公序良俗（如"净身出户"式惩罚条款效力存疑）。
- **"办了婚礼就是夫妻"**：错。1049条：**登记**才确立婚姻关系。同居≠婚姻，同居期间财产按共有/合伙处理，不适用1062条。
- **"离婚冷静期可以跳过"**：不能。1077条是强制程序；想快只能诉讼离婚（1079条）。
- **"出轨方离婚必须净身出户"**：法律没有净身出户。1087条照顾无过错方+1091条损害赔偿是法定上限，多分≠全拿。

## Key Takeaways

1. 1064条"共债共签"：大额债务让配偶签字，否则风险自担——债权人和债务人两端都要记住。
2. 1065条约定财产制是家企风险隔离的工具，但对抗第三人须公示。
3. 1077条离婚冷静期改变了协议离婚的节奏，涉资产处置要留足时间。
4. 1091条离婚损害赔偿的四种法定情形，是婚姻过错方的代价清单。
5. 婚姻家庭编是继承编的前置：夫妻财产先分割，才有个人遗产可继承。
