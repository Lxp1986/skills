# 第二编 物权（第205–462条）

## Core Idea
物权是对物的直接支配权，核心逻辑是**公示公信**：不动产看登记（209条），动产看交付（224条）。做生意凡涉及买房、买地、买设备、设抵押、做担保，都在物权编的射程内。它回答三个问题：这东西是谁的？怎么从一个人转到另一个人手里？欠钱时拿什么担保最稳？

## 关键条文

**通则**
- 第205条：本编调整因物的归属和利用产生的民事关系
- 第209条：不动产物权的设立、变更、转让、消灭，**经登记发生效力**；未经登记不发生效力（买房不办过户=没买到）
- 第215条：物权合同自成立时生效，**未办登记不影响合同效力**（合同有效≠物权转移——卖方一房二卖，合同都有效，但房子归先登记的人）
- 第224条：动产物权自**交付**时转移
- 第228条：特殊动产（船舶、航空器、机动车）——交付转移所有权，**登记对抗**第三人（买车不过户，车是你的，但不能对抗善意第三人）

**所有权与业主权利**
- 第240条：所有权=占有、使用、收益、处分的完整权能
- 第271条：建筑物区分所有权（专有部分所有权+共有部分共有权+共同管理权）
- 第278条：业主共同决定事项的表决规则（面积+人数双三分之二/双四分之三）
- 第279条：住改商——需有利害关系的业主一致同意（开公司用住宅地址的合规前提）
- 第281条：维修资金属业主共有；第286条：业主遵守管理规约、配合物业

**善意取得**
- 第311条：无权处分下，受让人**善意+合理价格+已登记/交付**即取得所有权（买二手设备、收二手房时"善意"的举证价值；原所有人只能向无权处分人索赔）

**用益物权**
- 第349条：建设用地使用权自**登记**时设立；第350条：不得擅自改变土地用途
- 第354条：建设用地使用权转让、抵押须书面合同
- 第359条：**住宅建设用地使用权期限届满自动续期**（70年产权到期不等于收回）
- 第366条：居住权——对他人住宅占有、使用的用益物权（以房养老、离婚房产安排的新工具）
- 第368条：居住权不得转让、继承（登记设立后专属）
- 第397条：建筑物抵押时占用范围内的建设用地使用权一并抵押（房地一体）

**担保物权（商事核心）**
- 第392条：人保与物保并存时——有约定按约定；无约定时，**债务人自己提供物的担保的先执行该物保**，第三人物保则债权人可任选（担保结构设计的关键）
- 第394条：抵押——不转移占有；第395条：可抵押财产范围
- 第401条：**流押禁止**——履行期届满前约定"到期不还房归我"的条款无效，只能就抵押财产优先受偿
- 第402条：不动产抵押**登记设立**；第403条：动产抵押合同生效即设立，**未经登记不得对抗善意第三人**（动产抵押务必登记！）
- 第406条：**抵押期间抵押人可以转让抵押财产**，抵押权不受影响（民法典重大变化：告别"未经同意不得转让"）
- 第414条：同一财产多重抵押的清偿顺序（登记优先）；第415条：抵押与质权并存按登记/交付时间先后
- 第420–421条：最高额抵押——为连续发生的债权提供担保（银行授信的常用工具）
- 第425条：动产质权——**转移占有**设立；第428条：流质禁止
- 第440条：可出质的权利范围；第441条：票据、仓单等交付设立；第444条：知识产权出质登记设立；**第445条：应收账款出质登记设立**（供应链金融、保理的法律基础）
- 第447条：留置权——合法占有债务人动产+债务到期未履行即可留置（承揽人、保管人、运输人的天然武器）；第453条：留置财产后给债务人不少于60日的履行宽限期

**占有**
- 第458–462条：占有的保护（即使是无权占有，被侵夺也可请求返还——施工现场、租赁物的现实意义）

## 商事实务要点

1. **买房买地只看登记**：签了买卖合同≠拥有物权（215条）。二手房交易必须完成过户登记；买在建工程、土地，查不动产登记簿是唯一可靠动作。
2. **动产抵押必须登记**：设备抵押给银行，不去办动产抵押登记，遇到善意第三人就输（403条）。登记在中国人民银行征信中心动产融资统一登记公示系统办理。
3. **担保结构设计**：既有抵押又有保证时，合同中**明确约定实现顺序**（392条），否则默认先执行债务人自己的物保——债权人想先找保证人要钱，必须在合同里写明。
4. **应收账款质押/保理**：445条+761条（保理合同）是供应链金融的法律地基，同样要登记公示。
5. **406条的双刃剑**：抵押物可自由转让——做抵押权人要在合同中约定转让通知/提前清偿条款；做买方买抵押房/抵押设备，查登记、要求涤除抵押。
6. **留置权是天然免费担保**：承揽、运输、保管、行纪业务中，对方不付钱，先合法留置货物再谈判（447条），但注意60日宽限期（453条）。
7. **租赁物业开店**：279条住改商需利害关系业主一致同意——签租约前确认合规，否则合同可能被认定无效。

## 常见误区 / 反模式

- **"合同签了，房子就是我的了"**：错。215条：合同有效，但物权没转移。一房二卖时，房子归先办登记的人，没买到的人只能追究违约责任。
- **"抵押物未经我同意卖了，抵押权就没了"**：错。406条：抵押人可转让，抵押权**追及**抵押物。买抵押物前必须查登记。
- **"到期不还款，抵押的房子直接归我"**：错。401条流押禁止——只能拍卖变卖后优先受偿，直接以物抵债的约定无效。
- **"动产抵押合同签了就万事大吉"**：错。不登记不得对抗善意第三人（403条），等于裸奔。
- **"保证+抵押双保险，想先找谁就找谁"**：错。有约定从约定，无约定先看是谁的物保（392条）。

## Worked Example

**场景**：C公司向银行借款5000万，以自有厂房抵押（已登记），同时由D公司提供连带责任保证。C公司到期无力还款。银行想直接要求D公司代偿，可以吗？

**分析**：
1. 担保结构：物的担保（C公司自己的厂房抵押）+ 人的担保（D公司保证）并存——适用392条。
2. 查合同约定：若保证合同/借款合同中约定"债权人可选择实现顺序"，按约定，银行可直接找D公司。
3. 若无约定：厂房是**债务人自己**提供的物保，银行**应当先就该厂房实现债权**，不足部分再找D公司。
4. 厂房拍卖流程中，C公司若转让厂房（406条允许），抵押权追及，银行优先受偿权不受影响。

**结论**：银行要在担保合同中预先约定实现顺序；D公司作为保证人，签约时要看清自己是"第二还款来源"还是"任选"。

## Key Takeaways

1. 不动产看登记、动产看交付——这是物权的一切起点（209/224条）。
2. 合同有效≠物权转移（215条），一房二卖、设备重复抵押的纠纷都从这里判。
3. 动产抵押、应收账款质押**必须登记**，否则对抗不了第三人（403/445条）。
4. 流押流质条款一律无效（401/428条），到期不还只能走拍卖变卖。
5. 人保+物保并存，**实现顺序写进合同**（392条），默认规则可能不符合你的预期。
