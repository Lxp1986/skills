# 第六编 继承（第1119–1163条）

## Core Idea
继承编是"财富交接"的法律。它只回答：人去世后，财产按什么顺序、什么方式传下去。对企业主而言，这是**家企传承**的核心法律：公司股权、房产、存款怎么传给下一代，遗嘱怎么写才有效。顺序是：遗赠扶养协议＞遗嘱＞法定继承（1123条）。

## 关键条文

**一般规定**
- 第1121条：继承从被继承人**死亡时**开始
- 第1122条：遗产=自然人死亡时遗留的**个人合法财产**（注意"个人"二字——夫妻共同财产先分割出一半，剩下才是遗产）
- 第1123条：继承顺序——**有遗赠扶养协议按协议，有遗嘱按遗嘱**，都没有才法定继承
- 第1124条：放弃继承须在遗产处理前**书面**表示；没表示=接受
- 第1125条：丧失继承权的情形（故意杀害被继承人、为争夺遗产杀害其他继承人、遗弃虐待情节严重、伪造篡改隐匿销毁遗嘱情节严重、胁迫欺诈违背真实意思等）

**法定继承**
- 第1127条：**第一顺序**：配偶、子女、父母；**第二顺序**：兄弟姐妹、祖父母、外祖父母（有第一顺序的，第二顺序不继承）
- 第1128条：**代位继承**——子女先于被继承人死亡的，由其直系晚辈血亲代位
- 第1129条：丧偶儿媳/女婿尽主要赡养义务的，作为**第一顺序**继承人
- 第1130条：同一顺序份额**一般均等**（尽主要扶养义务/共同生活的**可多分**，有扶养能力不尽义务的**少分或不分**）
- 第1131条：继承人以外的依靠被继承人扶养的人可酌情分得遗产

**遗嘱继承**
- 第1133条：自然人可立遗嘱处分个人财产，并可指定**遗嘱执行人**
- 第1134条：**自书遗嘱**——亲笔书写+签名+注明年月日
- 第1135条：**代书遗嘱**——2个以上见证人在场，1人代书，遗嘱人+代书人+其他见证人签名+年月日
- 第1136条：**打印遗嘱**——2个以上见证人在场，遗嘱人和见证人**在每一页**签名+年月日（民法典新增，适配现代习惯）
- 第1137条：**录音录像遗嘱**——2个以上见证人在场，记录姓名肖像+年月日
- 第1138条：**口头遗嘱**——仅限危急情况，2个以上见证人；危急消除后能书面/录音录像的，口头遗嘱**无效**
- 第1139条：**公证遗嘱**——经公证机构办理（注意：民法典**取消了公证遗嘱效力优先**，多份遗嘱以最后一份为准）
- 第1140条：无/限制行为能力人、继承人受遗赠人、与继承人有利害关系的人**不能做见证人**
- 第1141条：**必留份**——为缺乏劳动能力又无生活来源的继承人保留必要份额（遗嘱不能剥夺）
- 第1142条：遗嘱人可**撤回、变更**自己的遗嘱；第1143条：遗嘱无效情形

**遗产处理**
- 第1145条：**遗产管理人**——遗嘱执行人为管理人；无执行人的继承人推选；无人时的民政部门/村委会担任（民法典新增制度，解决"遗产无人管"的真空）
- 第1154条：遗产分割的法定办理情形；第1159条：分割遗产先清偿**税款和债务**，但须为缺乏劳动能力又无生活来源的继承人保留必要份额
- 第1160条：无人继承又无人受遗赠的遗产**归国家**（用于公益事业）

## 商事实务要点

1. **企业主必立遗嘱**：公司股权、房产、存款，不立遗嘱=法定继承多人共有——公司可能陷入"多个继承人当股东"的僵局。遗嘱中明确股权由谁继承，并指定遗嘱执行人（1133/1145条）。
2. **遗嘱形式合规**：最常用的是自书（1134条）+打印（1136条）。打印遗嘱**每一页**都要签名+见证人签名，缺一页=整份风险。见证人避开继承人及其利害关系人（1140条）。
3. **多份遗嘱以最后为准**：1139条取消公证优先——想变更遗嘱，重立一份注明日期即可，不必再跑公证处。但为减少争议，重要遗嘱仍建议公证+录像双保险。
4. **债务先于分割**：1159条——被继承人的债务（银行贷款、担保）要在分割前清偿。继承人只在**所得遗产实际价值范围内**承担债务（第1161条，限定继承原则），超出部分可不还——但放弃继承（1124条）与限定继承的策略选择要算账。
5. **遗赠扶养协议优先**：1123条——与保姆/亲属签遗赠扶养协议（生养死葬+财产归其），效力**高于遗嘱**。家族企业传承中可用于安排非继承人的照顾者。
6. **婚内财产先分割**：1122条"个人合法财产"——先按1062/1065条分出配偶的一半，剩下才是遗产。遗嘱处分全部夫妻共同财产的部分无效。

## 常见误区 / 反模式

- **"公证遗嘱效力最高，立了就不能改"**：错。民法典取消公证优先（1139条），最后一份遗嘱为准。但实践中仍建议公证+录像，防"最后一份"的真伪争议。
- **"遗嘱可以不给某个子女留任何东西"**：看情况。1141条必留份：缺乏劳动能力又无生活来源的继承人必须保留份额，否则遗嘱部分无效。
- **"口头交代了就行"**：错。1138条口头遗嘱仅限危急情况+2个见证人，危急消除后必须补书面/录像，否则无效。
- **"继承人要还被继承人的全部债务"**：错。限定继承——以所得遗产为限（1159条方向）。但**别先花掉遗产再谈债务**，顺序不能反。
- **"打印遗嘱签个名就行"**：错。1136条：遗嘱人+见证人**每一页**签名+年月日，缺页=形式瑕疵。

## Key Takeaways

1. 继承顺序：遗赠扶养协议＞遗嘱＞法定继承（1123条）——想按自己意愿传，先写遗嘱。
2. 第一顺序：配偶、子女、父母（1127条）；代位继承只向下传一代（1128条）。
3. 五种遗嘱形式中，打印遗嘱（1136条）最实用但形式要求最细。
4. 1145条遗产管理人是新工具，复杂遗产（公司股权、多处房产）务必指定。
5. 夫妻共同财产先分割（1062条），再谈遗产（1122条）——顺序错了，遗嘱白立。
