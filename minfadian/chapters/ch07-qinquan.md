# 第七编 侵权责任（第1164–1258条）

## Core Idea
侵权责任是"做错事要赔"的法律。归责上三档：**过错责任**（1165条，默认）、**无过错责任**（1166条，法律明文规定的才适用）、**过错推定**（部分特殊侵权）。对企业主的意义：用工风险（1191条）、产品风险（1202条）、经营场所风险（1198条）、网络言论风险（1194条）——这四块是企业侵权责任的全部家当。

## 关键条文

**一般规定（第1164–1183条）**
- 第1165条：行为人**因过错**侵害他人民事权益造成损害的，承担侵权责任（默认规则：谁主张谁举证过错）
- 第1166条：**无过错责任**——法律规定应当承担的，不论有无过错（产品、环境、高度危险、动物等特殊领域）
- 第1167条：侵权行为危及他人人身财产安全的，可请求停止侵害、排除妨碍、消除危险（**诉前/诉中禁令**）
- 第1172条：分别侵权按责任大小分担；第1173条：被侵权人有过错可减轻侵权人责任（混合过错）
- 第1174条：损害因**受害人故意**造成的，行为人不担责
- 第1176条：**自甘风险**——自愿参加有一定风险的文体活动，因其他参加者行为受损的，不得请求赔偿（剧烈运动、团建拓展的组织者要知道这条）
- 第1177条：正当防卫、紧急避险（防卫过当、避险过当仍要担责，但可减轻）
- 第1179条：人身损害赔偿项目（医疗费、护理费、交通费、营养费、住院伙食补助费、误工费、残疾赔偿金等）
- 第1180条：同一侵权致多人死亡可**同命同价**
- 第1181条：被侵权人死亡的，近亲属可请求赔偿
- 第1182条：财产损失按**被侵权人损失或侵权人获利**赔偿
- 第1183条：**精神损害赔偿**——侵害人身权益造成严重精神损害的，被侵权人可请求（人格权侵权的配套救济）

**责任主体特殊规定（第1188–1201条）**
- 第1188条：无/限制行为能力人致损由**监护人**担责
- 第1189–1190条：教唆、帮助他人侵权的连带责任
- 第1191条：**用人单位责任**——工作人员因执行工作任务致损，**由用人单位承担**（员工开车送货撞人、客服言语侵权，公司买单；公司可向有故意/重大过失的员工追偿——内部制度要写清）
- 第1192条：个人劳务关系（接受劳务一方担责）；第1193条：承揽关系（定作人**一般不担责**——发包工程、委托加工时选承揽关系可隔离风险，但选任/指示有过失的除外）
- 第1194–1195条：**网络侵权**——网络用户、网络服务提供者侵权担责；权利人可**通知**平台采取删除、屏蔽、断开链接等措施（1195条"通知—删除"规则：被诽谤、被盗图，先发通知函给平台）
- 第1198–1201条：**安全保障义务**——宾馆、商场、银行、车站、机场、体育场馆、娱乐场所等经营者/管理者未尽安全保障义务致损的，担责（商场滑倒、酒店被盗、展会踩踏——经营场所的日常合规：监控、警示、巡查记录）

**产品责任（第1202–1207条）**
- 第1202条：产品缺陷致损，**生产者**担责（无过错责任）
- 第1203条：被侵权人可向**生产者或销售者**任选其一索赔（被追偿方可再追偿）
- 第1207条：**惩罚性赔偿**——明知缺陷仍生产销售、造成死亡或健康严重损害的，被侵权人可请求惩罚性赔偿（食品、药品、母婴产品的红线中的红线）

**机动车交通事故责任（第1208–1217条）**
- 第1208–1213条：先由交强险赔，超出按过错分担（1213条）
- 第1209条：租赁、借用车辆出事故，**使用人**担责（车主无过错不担责——租车、借车的权责）
- 第1210条：已转让交付但未过户的，**受让人**担责
- 第1212条：未经允许驾驶他人机动车（盗开、私开），使用人担责
- 第1217条：**好意同乘**——无偿搭乘出事故属机动车方责任的，**减轻**赔偿责任（顺风车、朋友搭车的法律后果）

**医疗损害责任（第1218–1228条）**
- 第1218条：医务人员有过错的，**医疗机构**担责
- 第1219条：**知情同意**——手术、特殊检查治疗须向患者说明并取得明确同意（美容、体检机构的合规重点）
- 第1221条：未尽到相应诊疗义务的推定过错；第1225条：病历书写保管义务（病历是医疗纠纷的第一证据）

**环境污染与生态破坏（第1229–1235条）**
- 第1229条：污染环境致损担责（无过错）
- 第1230条：**举证责任倒置**——行为人须证明法定免责情形及行为与损害无因果关系（原告只证"污染+损害"，被告自证清白）
- 第1232条：**惩罚性赔偿**——故意污染、破坏生态造成严重后果的（ESG合规的牙齿）

**高度危险责任（第1236–1244条）**：从事高空、高压、易燃易爆、剧毒等作业致损，无过错担责（化工、建筑、能源企业的特殊风险）

**饲养动物损害责任（第1245–1251条）**
- 第1245条：动物致损饲养人/管理人担责（被侵权人故意/重大过失可减免）
- 第1247条：**禁止饲养的烈性犬等危险动物**致损，**无任何减免**（养禁养犬=无限责任）

**建筑物和物件损害责任（第1252–1258条）**
- 第1252–1253条：建筑物倒塌/脱落致损，建设单位、施工单位、所有人/管理人/使用人按情形担责
- 第1254条：**高空抛物**——禁止；侵权人担责；难确定时经调查的**可能加害的建筑物使用人补偿**（物业、业委会、业主的共同风险——监控全覆盖是物业的护身符）
- 第1255–1258条：堆放物、公共道路障碍、林木、施工挖掘致损

## 商事实务要点

1. **用工风险隔离**（1191–1193条）：员工执行工作任务致损公司买单——驾驶员、外勤、客服是高风险岗位，配保险+操作规程+追偿制度。用承揽而非雇佣处理外部作业（1193条定作人一般不担责），但**选任和指示**不能有过失。
2. **经营场所安全**（1198条）：商场、酒店、餐厅、展会——防滑、警示标识、监控、巡查记录，一个不能少。1198条是"未尽义务"才担责，**留痕就是免责证据**。
3. **产品合规**（1202–1207条）：生产者无过错担责+1207条惩罚性赔偿——食品、药品、儿童产品、电器，质量体系和产品责任险是标配。销售者被索赔后可向生产者追偿，进货查验记录要留。
4. **网络舆情与电商**（1194–1195条）：被侵权时立即向平台发**书面通知**要求删帖断链（写清权属证明+侵权链接）；作为平台/店主要建通知处理流程，接到通知不处理=连带责任。
5. **环境合规**（1229–1232条）：1230条举证倒置+1232条惩罚性赔偿——排污企业环评、监测数据、应急预案缺一不可，违法成本不再是"罚点款了事"。
6. **车辆管理**（1209–1213条）：公车私用、员工借车——1209条使用人担责，但车主有过错（如借给无证人员）仍担责。车队管理制度+交强险+商业险足额。
7. **高空抛物**（1254条）：物业企业须"采取必要的安全保障措施"（监控、巡查、宣传），否则可能担责。业主群里普法+装监控，是成本最低的风控。

## 常见误区 / 反模式

- **"员工自己闯的祸，公司不负责"**：错。1191条：执行工作任务致损，**用人单位担责**。想免责，证明员工行为与工作无关。
- **"发包出去就没我事了"**：基本对（1193条），但选任无资质的承揽人、指示错误的，定作人要担选任/指示过失责任。
- **"产品是我代工的，品牌方负责"**：错。1203条：被侵权人可向**生产者或销售者任选**索赔。代工厂和品牌方，一个都跑不了（内部再追偿）。
- **"高空抛物找不到人就没办法"**：错。1254条：经调查难以确定侵权人的，**可能加害的建筑物使用人给予补偿**——整栋楼分摊，倒逼物业和业主装监控。
- **"自甘风险=组织者免责金牌"**：错。1176条只免**其他参加者**的责任；组织者未尽安全保障义务（1198条）照样担责。团建、赛事主办方别拿1176条当挡箭牌。

## Worked Example

**场景**：H公司员工小王开公司货车送货途中闯红灯撞伤行人。行人起诉H公司和小王。H公司称"闯红灯是小王个人违法，公司不应担责"。

**分析**：
1. 归责：1191条——小王系执行工作任务（送货），**H公司承担侵权责任**，闯红灯不改变"执行工作任务"的定性。
2. 小王个人：对被侵权人不直接担责；H公司赔偿后，若小王有**故意或重大过失**（闯红灯可认定重大过失），H公司可依据内部制度/劳动合同向其追偿。
3. 若小王是下班后私开公车办私事——非执行工作任务，H公司可主张不适用1191条，但车主管理过错（1209条方向：未妥善管理车辆）仍可能担责。
4. 保险：交强险先赔（1213条），商业三者险补充。

**结论**：公司为员工职务行为买单是法定的；风控=驾驶员管理制度+车辆GPS/行车记录+足额保险+内部追偿条款。

## Key Takeaways

1. 1165条过错责任是默认，1166条无过错责任只在法律明文时适用——先定归责原则，再谈赔偿。
2. 企业的四大侵权风险敞口：用工（1191条）、产品（1202条）、场所（1198条）、网络（1194条）。
3. 1193条承揽关系是发包方的风险隔离墙，但选任指示过失是缺口。
4. 1207条（产品）和1232条（环境）的惩罚性赔偿，是悬在特定行业头上的剑。
5. 1254条高空抛物：找不到侵权人时整栋补偿——物业的监控投入是最便宜的保险。
