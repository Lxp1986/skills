# 第四编 人格权（第989–1039条）

## Core Idea
人格权独立成编是民法典的最大创新之一。它保护的是"作为人"的基本尊严：生命、身体、健康、姓名、肖像、名誉、隐私、个人信息。对做生意的Lin而言，意义有三：**企业用工**（员工隐私、个人信息）、**品牌营销**（代言人肖像、用户评价与名誉权）、**舆情风控**（被侵权时如何快速止损）。

## 关键条文

**一般规定（第989–1001条）**
- 第990条：人格权种类——生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等
- 第991条：人格权受法律保护，任何组织或个人不得侵害
- 第992条：**人格权不得放弃、转让或继承**（与财产权最根本的区别——买不来、卖不掉）
- 第993条：可将姓名、名称、肖像等**许可他人使用**（代言合同的法律基础；许可≠转让）
- 第994条：死者的姓名、肖像、名誉、荣誉、隐私、遗体受侵害的，近亲属可维权
- 第995条：人格权请求权（停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉）——**不适用诉讼时效**（196条）
- 第996条：违约造成对方人格权损害+严重精神损害的，可同时主张精神损害赔偿
- 第997条：**人格权禁令**——有证据证明正在或即将被侵害、不及时制止将造成难以弥补损害的，可向法院申请人格权侵害禁令（舆情危机、恶意诽谤时的"急诊"程序）
- 第998条：认定侵害人格权责任时考虑双方职业、影响范围、过错程度等因素
- 第999条：为公共利益的新闻报道、舆论监督可**合理使用**他人姓名、肖像、个人信息（合理边界看998条因素）
- 第1000条：消除影响、恢复名誉、赔礼道歉须与行为方式和造成的影响相当
- 第1001条：身份权保护参照适用

**生命权、身体权、健康权（第1002–1005条）**
- 第1002条：生命权（生命安全和生命尊严）；第1003条：身体权；第1004–1005条：健康权
- 第1007条：**禁止任何形式买卖人体细胞、组织、器官、遗体**
- 第1008条：临床试验须经主管部门批准+伦理审查+知情同意
- 第1009条：人体基因、人体胚胎科研须遵守国家规定（生物科技创业的红线）

**姓名权、名称权（第1012–1017条）**
- 第1012条（第一千零一十二条）：自然人享有姓名权，可依法决定、使用、变更或许可他人使用，但不得违背公序良俗
- 第1014条：不得干涉、盗用、假冒他人姓名
- 第1017条：有一定社会知名度者的姓名被抢注等造成公众混淆的，参照适用

**肖像权（第1018–1023条）**
- 第1018条（第一千零一十八条）：自然人享有肖像权，可依法制作、使用、公开或许可他人使用
- 第1019条：**未经肖像权人同意，不得制作、使用、公开其肖像**（营销用客户照片、员工形象做广告，必须书面授权）
- 第1020条：合理实施行为不构成侵权（如为个人学习、新闻报道、国家机关履职等——但商业广告不在此列）
- 第1021–1023条：肖像许可使用合同的解释规则、解除

**名誉权、荣誉权（第1024–1031条）**
- 第1024条：任何组织或个人不得以侮辱、诽谤等方式侵害名誉权
- 第1025条：行为人发表的文学、艺术作品以真人真事为描述对象的合理使用
- 第1027条：**信用评价**——公共信用信息须客观公正，不得误导（企业征信、平台评分的合规边界）

**隐私权、个人信息保护（第1032–1039条）**
- 第1032条：隐私权——不得以刺探、侵扰、泄露、公开等方式侵害（私人生活安宁、私密空间、私密活动、私密信息）
- 第1034条：个人信息受法律保护（姓名、出生日期、身份证件号码、生物识别信息、住址、电话、行踪等）
- 第1035–1038条：处理个人信息的**合法、正当、必要**原则，须征得同意、明示目的方式范围；不得过度收集；保障信息安全（配合《个人信息保护法》使用——HR收集员工信息、APP收集用户数据的合规框架）

## 商事实务要点

1. **代言与广告**：用真人（明星、KOL、员工、客户）做广告/包装，必须签**肖像许可合同**（993/1018条），写明使用范围、期限、地域、报酬。超范围使用=侵权。
2. **员工个人信息**：入职收集身份证、银行账号、健康信息，要告知目的+征得同意+最小必要（1035条）；离职后及时删除或匿名化。背景调查别碰"刺探"红线（1032条）。
3. **用户评价与名誉权**：客户给差评≠侵权；但组织水军编造事实诋毁竞争对手=侵害法人名誉权（1024条）。法人的名誉权同样受保护。
4. **舆情应急**：被恶意诽谤、人肉搜索时，997条人格权禁令可快速要求法院责令停止（配合证据保全）。同时按1195条（网络侵权通知）要求平台删帖。
5. **信用与背调**：对外发布供应商"黑名单"、员工负面评价，要确保事实依据（1027条），否则构成名誉侵权。

## 常见误区 / 反模式

- **"公众人物没有隐私"**：错。999条的合理使用有边界，捏造事实、过度曝光私生活照样侵权。
- **"签了劳动合同就能随便用员工照片宣传"**：错。肖像许可（993条）是独立授权，劳动合同≠肖像许可。
- **"死者没有权利，爱怎么写怎么写"**：错。994条：近亲属可为死者维权。
- **"用户注册时点了同意，数据随便用"**：错。1035条：处理须与明示目的直接相关，超范围使用、过度收集都违法。
- **"人格权也能转让/继承"**：错。992条明确不得转让继承——"买断肖像权"合同的实质是长期独占许可，不是所有权转移。

## Key Takeaways

1. 人格权独立成编=民事权利保护的重心从"财产"扩展到"人"（990–992条）。
2. 997条人格权禁令是舆情/诽谤危机的快速止损工具，记住它的存在。
3. 凡涉及真人形象、个人信息，先拿授权（993/1018/1035条），再谈业务。
4. 企业的名誉权同样受保护（1024条），但维权要过"事实依据"关。
5. 生物科技、基因、人体试验（1007–1009条）是绝对红线，创业选赛道时先查。
