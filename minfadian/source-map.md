# 来源与版本说明（Source Map）

## 法典版本

- **名称**：《中华人民共和国民法典》
- **通过**：2020年5月28日，第十三届全国人民代表大会第三次会议
- **公布**：中华人民共和国主席令第45号
- **施行**：2021年1月1日起施行
- **结构**：7编、1260条
  - 第一编 总则：第1–204条
  - 第二编 物权：第205–462条
  - 第三编 合同：第463–988条
  - 第四编 人格权：第989–1039条
  - 第五编 婚姻家庭：第1040–1118条
  - 第六编 继承：第1119–1163条
  - 第七编 侵权责任：第1164–1258条
  - 附则：第1259–1260条
- **同时废止**：婚姻法、继承法、民法通则、收养法、担保法、合同法、物权法、侵权责任法、民法总则（第1260条）
- **文本来源**：公开渠道民法典全文（2026-09核验为现行有效版本），经去杂质清洗
- **Skill生成日期**：2026-10-02

## 内容边界

1. 本 skill 为法典正文的**提炼、结构化与商事实务解读**，不全文复制法条，不收录司法解释、指导性案例、地方性法规。
2. 民法典配套有大量**司法解释**（如买卖合同、保证、建设工程、婚姻家庭、继承、侵权责任等司法解释），实务中与法条同等重要，本 skill 未覆盖，须另行查阅。
3. 法律处于持续修订中（如司法解释更新、个别条款修正）。本 skill 是**静态知识**，不能证明所引条文在未来仍现行有效。
4. 条文引用均经原文核验（核验记录见构建过程），但解读带有提炼性质，**原文表述为准**。

## 使用要求（必读）

- 涉及真实交易、诉讼、婚姻家庭、遗产、人身权益或重大财产事项时，**必须**到"国家法律法规数据库"（flk.npc.gov.cn）、最高人民法院官网等官方渠道核对**现行有效文本**、相关司法解释和施行时间。
- 本 skill 不构成法律意见。重大事项须咨询**持牌律师**，结合具体事实与证据判断。
- 跨境、涉外业务另涉冲突法（《涉外民事关系法律适用法》），不在本 skill 范围内。
