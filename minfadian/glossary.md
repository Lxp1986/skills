# 术语表（Glossary）

按拼音排序。条号为民法典原文位置。

**不安抗辩权** — 先履行方有确切证据证明对方经营恶化、转移资产等情形时，可中止履行（第527条，ch03）
**表见代理** — 相对人有理由相信无权代理人有代理权时，代理行为对被代理人有效（第172条，ch01）
**不动产物权登记生效主义** — 不动产物权经登记才发生效力（第209条，ch02）
**除斥期间** — 权利存续期间，届满权利消灭，不适用中止中断（如撤销权1年/5年，第541条；解除权，第564条；保证期间，第692条）
**代位权** — 债务人怠于行使债权影响债权人到期债权实现时，债权人可代位行使（第535–536条，ch03）
**担保物权** — 为担保债务履行，在债务人或第三人财产上设定的优先受偿权，包括抵押权、质权、留置权（第386条起，ch02）
**高空抛物** — 禁止从建筑物抛掷物品；难确定侵权人时可能加害的建筑物使用人补偿（第1254条，ch07）
**格**式条款 — 预先拟定、订立时未与对方协商的条款；争议时作不利于提供方解释（第496–498条，ch03）
**共债共签** — 夫妻共同债务须双方共同意思表示或用于家庭日常生活需要（第1064条，ch05）
**过错推定** — 法律推定行为人有过错，行为人须自证无过错（如医疗1221条方向、环境1230条举证倒置）
**过错责任** — 因过错侵害他人民事权益才担责，侵权责任的默认归责原则（第1165条，ch07）
**好意同乘** — 无偿搭乘出事故属机动车方责任时减轻赔偿（第1217条，ch07）
**合同相对性** — 依法成立的合同仅对当事人有约束力（第465条，ch03）
**检**验义务 — 买受人收到标的物应及时检验（第620条，ch03）
**居住权** — 对他人住宅占有、使用的用益物权，不得转让继承（第366–371条，ch02）
**流押/流质禁止** — 履行期届满前约定"到期不还财产归债权人"的条款无效（第401条抵押/第428条质押，ch02）
**买卖不破租赁** — 租赁物所有权变动不影响租赁合同效力（第725条，ch03）
**缔约过失** — 订立合同过程中的欺诈、恶意磋商、泄密等致损须赔偿（第500条，ch03）
**情势变更** — 基础条件发生无法预见、非商业风险的重大变化时可请求变更/解除合同（第533条，ch03）
**人格权禁令** — 人格权正受/将受侵害且情况紧急时，可申请法院责令停止（第997条，ch04）
**善意取得** — 无权处分下，善意+合理价格+登记/交付的受让人取得所有权（第311条，ch02）
**诉讼时效** — 请求保护民事权利的期间，普通3年，最长20年（第188条，ch01）
**同时/先履行抗辩权** — 互负债务时一方在对方履行前可拒绝履行（第525–526条，ch03）
**无权代理** — 无代理权/越权/代理权终止后的代理，未经追认对被代理人不发生效力（第171条，ch01）
**无过错责任** — 法律明文规定的，不论有无过错均担责（第1166条，ch07）
**物权法定** — 物权种类和内容由法律规定，当事人不得创设（第116条方向，ch02）
**先诉抗辩权** — 一般保证人享有的"先告借款人"的权利（第687条，ch03）
**相**邻关系 — 不动产相邻权利人间的便利、容忍义务（第288–296条，ch02）
**遗**产管理人 — 负责保管、清理、分配遗产的人，遗嘱执行人优先担任（第1145条，ch06）
**债**权转让 — 债权人转让债权，通知债务人后对债务人生效（第545条，ch03）
**债**务加入 — 第三人加入债务与债务人共同承担，债权人可向任一方主张（第552条方向，ch03）
**债**务转移 — 债务人转移债务须经债权人同意（第551条，ch03）
**征**收征用 — 国家为公共利益可征收征用不动产动产并补偿（第243–245条，ch02）
**知**情同意 — 医疗手术、特殊检查治疗须向患者说明并取得明确同意（第1219条，ch07）
**自甘风险** — 自愿参加有风险文体活动受损，不得请求其他参加者赔偿（第1176条，ch07）
**最高额抵押** — 为一定期间连续发生的债权提供的最高限额担保（第420–421条，ch02）
