## 时效与期间速查

- 诉讼时效3年：起诉、催收、对方确认→**中断**重算（195条）；最后6个月障碍→**中止**（194条）
- 法院**不主动**适用时效——当事人必须主张（193条）
- 撤销权/解除权/保证期间是**除斥期间**：过期消灭，无中止中断（199/541/564/692条）
- 人格权请求权（停止侵害等）**不适用**诉讼时效（196条）

## 决策规则（When X, do Y）

- 对方签约代表身份不明 → 要书面授权委托书；公章+长期交易惯例=表见代理风险（172条）
- 保证合同没写保证方式 → 默认**一般保证**（先诉抗辩），债权人务必写明"连带责任保证"（686条）
- 人保+物保并存 → 先看合同有无约定实现顺序；无约定先执行债务人自己的物保（392条）
- 动产抵押/应收账款质押 → **必须登记**，否则对抗不了第三人（403/445条）
- 到期不还想直接拿走抵押物 → 不行，流押禁止（401条）；走拍卖变卖优先受偿
- 对方经营恶化想中止供货 → 需**确切证据**+书面通知（527条不安抗辩），证据不足=自己违约
- 想解除合同 → **书面通知**，到达生效，留送达证据（565条）
- 借钱给已婚人士做生意 → 让其**配偶共同签字**，否则大概率只能追一人（1064条）
- 被网络诽谤/盗图 → 立即向平台发书面通知要求删除断链（1195条）；紧急可申请人格权禁令（997条）
- 员工职务行为致损 → 公司担责（1191条）；对外发包用承揽关系隔离（1193条）
- 企业主传承 → 遗嘱+约定财产制+遗产管理人三件套（1133/1065/1145条）
- 遗产债务 → 继承人以**所得遗产实际价值为限**清偿（1161条）

## 高频风险信号（Tells）

- 合同里出现"概不负责""最终解释权归本公司"→ 格式条款无效风险（497条）
- 对方要求"保证"但不肯写连带 → 他在给你挖一般保证的坑（686条）
- 抵押合同约定"到期不还房归我"→ 流押条款无效（401条）
- 离婚协议约定"净身出户"→ 无法律依据，1087/1091条是上限
- 口头承诺变更合同 → 推定未变更（544条），必须书面

## 紧急联系人（条文级）

- 被侵权急需止损：997条（人格权禁令）、1167条（停止侵害）、1195条（网络通知删除）
- 对方转移资产：538–539条（撤销权，1年/5年除斥541条）
- 违约跑路前兆：527条（不安抗辩）、535条（代位权）
