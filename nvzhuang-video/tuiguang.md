# 推广方案 (tuiguang.md)

## 一、三平台差异打法

### 抖音：内容电商主战场

- **定位**：短视频种草 + 橱窗/小黄车直接成交。2026 年趋势：达播退潮，店播 + 商品卡 + 短视频带货是主流，中小商家不要幻想找大主播带货（ROI 约 1:1.2，品牌自播约 1:4.5）。
- **账号结构**：1 个主账号（真人出镜立人设）+ N 个矩阵号（AI 生成铺量）。矩阵号之间内容要有差异（不同人设/场景），不要一键分发同一条。
- **发布时间**：12:00-13:30（午休）、18:00-22:00（晚高峰）。测试 2 周后按自己账号的粉丝活跃时间微调。
- **冷启动**：新号前 10 条不投流，纯自然流量测内容。单条点赞率 >3% 或评论区"求链接"多，再考虑加热。
- **商品卡**：上架所有在售款到抖音商城商品卡，标题含精准长尾词（如"梨形身材显瘦半身裙"），吃搜索流量。这是免费的，不要漏。

### 小红书：种草 + 私域

- **定位**：种草心智最强，女性用户浓度最高。成交不一定在站内，但"被种草后去淘宝/抖音搜同款"是常态——小红书是放大器。
- **内容**：图文 + 视频都要做。图文适合公式 D（场景化，一张封面 + 3-5 张细节图）；视频用公式 B/E。
- **标题**：严格用 shipin.md 的标题公式，违禁词重点查（最/首/唯一/顶级/绝对/史上/封神）。
- **话题标签**：1-2 个大流量（#穿搭 #今日穿搭）+ 2-3 个精准长尾（#梨形身材穿搭 #小个子通勤装）。不要只堆大词。
- **发布时间**：8:00-9:00（通勤）、12:00-13:00（午休）、18:00-21:00（晚间）。
- **评论区**：小红书用户爱在评论区问"求链接"，及时回复 + 置顶购买指引。品牌名写的时候加空格（如"S K-II"式写法）规避广告识别——这是平台潜规则。

### 视频号：社交裂变 + 私域直连

- **定位**：微信生态内闭环，粉丝可以直接导到个人微信/社群，私域转化路径最短。中老年和下沉女性用户多，客单价 50-200 元最佳。
- **内容**：真人出镜优先（社交推荐吃真实感），AI 生成为辅。溯源类内容（"带你看广州档口拿货") 在视频号信任感极强。
- **发布时间**：19:00-22:00。保持每周 3-5 更。
- **冷启动**：每条发完转发到朋友圈 + 客户群，初始播放靠社交关系链，这是视频号和其他平台最大的不同。
- **直播**：条件允许时每周 1-2 场店播（30-60 分钟即可），话术："1 号链接引流款，3-5 号利润款"，每介绍完一款引导点购物车对应编号。店播是 2026 年平台明确扶持的方向。

## 二、DOU+ 投放策略

DOU+ 是放大器，不是救心丸。自然流量没跑出来的内容，投钱也救不回来。

### 投放前提（必须同时满足）

1. 视频发布 6 小时后自然流量数据：点赞率 >3%，或评论区有真实"求链接"评论 ≥5 条
2. 挂车商品有库存、价格是最优价（投流期间不许涨价）
3. 账号已发 ≥10 条内容（新号先养号）

### 投放实操

1. **测试**：100 元起投，定向选"系统智能推荐"或"相似达人"（选 3-5 个同类目腰部女装账号）。
2. **判断**：24 小时后看 ROI（投产比）。ROI > 1:2 → 加投；1:1.5-2 → 观察 12 小时；<1:1.5 → 停投，这条内容的问题不在流量在内容本身。
3. **加投**：每次加投不超过上一笔的 3 倍，阶梯加，不要一次砸大钱。
4. **人群包**：跑出 3 条以上正 ROI 的视频后，建"高转化人群包"复用。

### 不投的四种情况

- 新号前 10 条（先测内容）
- 纯人设/剧情内容（不带货的不投）
- 库存 <50 件的款（爆了发不出货 = 差评）
- 大促前 3 天（流量贵，等大促当天平台自然流量红利）

## 三、私域转化路径

公域流量是租来的，私域才是自己的。女装复购率高，私域价值极大。

### 路径设计

```
短视频/直播（公域）
  → 评论区钩子 / 直播口播 / 包裹卡："加微信领 10 元券 + 穿搭群"
    → 个人微信（企微或私微）
      → 标签分层：新客 / 复购 / 高客单 / 身材特征 / 风格偏好
        → 朋友圈种草（每天 2-3 条：新品 + 穿搭 + 客户返图）
        → 社群（每周 1 次专属秒杀 / 新品预告）
        → 复购 + 转介绍
```

### 分层运营

| 分层 | 策略 |
|---|---|
| 新客（加微 7 天内） | 发新人券 + 问身材风格偏好，打标签 |
| 活跃复购 | 新品优先通知 + 专属折扣 |
| 沉默（30 天无互动） | 发"久未见面"唤醒券 + 爆款返图 |
| 高客单 | 1v1 穿搭顾问 + 新品优先试穿 |

### 包裹卡（到店/快递必备）

每单放一张卡："扫码加微信，领 10 元无门槛券 + 进穿搭交流群，每周三群内专属秒杀"。这是成本最低的私域入口，不要省这张纸。

## 四、数据复盘

### 每周复盘表（每周一看 15 分钟）

| 指标 | 及格线 | 说明 |
|---|---|---|
| 完播率 | >30% | 低于 20% = 前 3 秒钩子废了，重做开头 |
| 点赞率 | >3% | 内容共鸣度 |
| 评论率 | >1% | 互动意愿，公式 B 应更高 |
| 转发率 | >0.5% | 种草价值，公式 D 应更高 |
| 收藏率 | >2% | "有用"程度 |
| 商品点击率 | >5% | 种草到购买的承接 |
| 加购率 | >10% | 价格/详情页问题定位 |
| 转化率 | >2% | 整体成交效率 |
| 退货率 | <40% | 高于 50% = 货不对版，详情页/视频夸大了，立刻整改 |

### 复盘决策

- **爆款**（完播+转化双高）：加投 DOU+、翻拍 3 条同公式不同款、商品卡加库存
- **哑火**（完播 <20%）：砍掉，不追加投放，分析是钩子问题还是款的问题
- **高流量低转化**：内容 OK，问题在价格/详情页/客服承接，调商品端
- **低流量高转化**：内容没推开但卖货效率高，加投 DOU+ 放大

### 月度动作

- 每月淘汰末位 20% 的款，补充新测款，保持货盘流动
- 每月盘一次私域：新增人数、复购率、客单价，私域 GMV 占比目标 >30%
